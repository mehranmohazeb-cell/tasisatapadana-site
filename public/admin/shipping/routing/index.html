قواعد ثابت مسیر ارسال ⓘ

  • داخل محدودهٔ رسمی شهر اصفهان: هر سبد → پیک موتوری، رایگان
  • خارج اصفهان، سبد عادی → ارسال عادی
  • خارج اصفهان، سبد دارای کالای غیرعادی → باربری + پس‌کرایه (گیرنده هنگام تحویل می‌پردازد)
  • حداکثر زمان ارسال از فروشگاه: ۳ روز (برای همهٔ روش‌ها؛ ارسال فوری فعال نیست)

ستون‌های Routing هنوز روی D1 ایجاد نشده‌اند (database/shipping-routing.sql). تا آن زمان همهٔ کالاها «عادی» حساب می‌شوند.
