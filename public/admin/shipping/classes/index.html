افزودن Shipping Class جدید

به‌جای وارد کردن هزینه ارسال برای تک‌تک محصولات، محصولات مشابه را در یک گروه حمل (مثلاً «سبک»، «سنگین»، «حجیم») قرار دهید و برای همان گروه در بخش Table Rates تعرفه تعریف کنید.

Shipping Class ماهیت حمل کالا را مشخص می‌کند و Route Policy سیاست مسیر همان کلاس است (فعلاً فقط «عادی» یا «باربری»). Packaging Profile فقط نحوهٔ برآورد بسته‌بندی را تعیین می‌کند و با این دو یکی نیست.
