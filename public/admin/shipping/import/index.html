Import تعرفه (CSV)

فایل CSV تعرفه را انتخاب کنید تا ابتدا پیش‌نمایش (اعتبارسنجی بدون ذخیره) نشان داده شود. ستون‌های شناخته‌شده: method_name/service، class_name، min_weight_grams/weight_min، max_weight_grams/weight_max، min_quantity/quantity_min، max_quantity/quantity_max، min_cart_value/cart_total_min، max_cart_value/cart_total_max، destination_city/destination/city، cost، priority، active. همان فایلی که از «Table Rates → خروجی CSV» گرفته‌اید هم مستقیماً قابل Import است. ردیف‌های خراب حذف می‌شوند؛ بقیه سیستم/ردیف‌های سالم دست‌نخورده وارد می‌شوند.
