حالت محاسبه ارسال

پیش‌فرض «فقط موتور داخلی» است — دقیقاً همان رفتار امروز سایت، بدون هیچ تغییری. تغییر این حالت فقط روی Endpoint پیش‌نمایش Admin اثر دارد؛ Checkout واقعی مشتری هنوز مستقیماً از موتور داخلی استفاده می‌کند تا وقتی یک Provider آنلاین واقعاً به API متصل و تست شود.

Providerهای ارسال

موتور داخلی همیشه فعال و غیرقابل‌غیرفعال‌سازی است (Fallback نهایی سیستم). Providerهای آنلاین (مثل Tapin) تا وقتی Credential/Endpoint واقعی متصل و تست نشده، غیرفعال می‌مانند.
